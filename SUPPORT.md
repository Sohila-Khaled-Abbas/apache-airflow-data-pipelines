# Support

## Getting Help

- **Open an Issue**: Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) templates.
- **Discussions**: Use GitHub Discussions for questions about the pipelines, architecture, or course materials.
- **Pull Requests**: For fixes and improvements, open a PR following [CONTRIBUTING.md](CONTRIBUTING.md).

## Learning Resources

- [Apache Airflow Documentation](https://airflow.apache.org/docs/)
- [Astronomer Academy](https://academy.astronomer.io/)
- [Udemy: Apache Airflow The Hands-On Guide](https://www.udemy.com/) (course materials in `course-materials/`)

## Community

This repo is published as learning evidence. While we welcome issues and PRs, please note that this is primarily an educational portfolio and support is provided on a best-effort basis.
